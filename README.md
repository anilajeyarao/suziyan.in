# suziyan.in

Static landing page for Suziyan AI, an AI services business focused on support, sales, and workflow automation for service companies.

## Files

- `index.html` - landing page structure and SEO metadata
- `styles.css` - visual system and responsive layout
- `script.js` - reveal-on-scroll interaction
- `CNAME` - custom domain for static hosting
- `robots.txt` - crawler rules
- `sitemap.xml` - sitemap for the main URL

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server.

## Hosting

This repo is designed to work well with:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
